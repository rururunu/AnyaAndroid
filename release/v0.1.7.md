# Anya Companion v0.1.7

After [v0.1.6](../CHANGELOG.md#016---2026-09-03): the download button in the generated-image / `![…](path:…)` fullscreen viewer now actually saves the file to Downloads.

Agent still runs on the PC. This app is a console: pair, chat, approve tools, and share files.

Requires a running desktop Anya with **Connect phone** / Remote Gateway enabled. Android 8.0+.

## What's new

- **Image download fix**: generated images and reply `![…](path:…)` tiles are cached locally under a `preview-…` id that never lands in `message.sharedFiles`, so the fullscreen viewer's download button used to no-op. It now resolves the preview cache and exports the real file to system **Downloads**; the button switches to **Open** once saved
- Download progress / success still uses the top banner (*Saved to Downloads*)

### Install

1. Download `Anya-v0.1.7.apk` below (or **Check for updates** on About if you already have an older build).
2. Open Anya on Windows → **Connect phone**, wait for the QR.
3. Scan. Prefer the same Wi-Fi as the PC.

Desktop: https://github.com/rururunu/Anya  
Docs: https://github.com/rururunu/AnyaAndroid

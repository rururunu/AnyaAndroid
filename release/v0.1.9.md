# Anya Companion v0.1.9

After [v0.1.8](./v0.1.8.md): a clearer results inbox, code-read snapshots, desktop defaults for new chats, and a refreshed launch experience.

Agent still runs on the PC. This app is a console for pairing, chatting, approvals, and shared files. Requires a running desktop Anya with **Connect phone** / Remote Gateway enabled. Android 8.0+.

---

## 中文

相对 [v0.1.8](./v0.1.8.md)：整理收件结果、增加代码读取快照、让新对话沿用配对桌面的默认设置，并更新启动体验。

### 本次更新

- **收件结果**：按对话分组，显示对话数与结果数；调整清空按钮和分组卡片布局，修复确认清空后无反应。清空只移除手机上的结果记录，不删除对话或已接收文件
- **代码读取**：展开成功的读取活动查看读取时快照；桌面支持 `session.readCodePreview` 时，可核对当前文件。文件变化或当前文件不可读时继续显示快照
- **新对话默认项**：从配对桌面获取并按设备缓存模型和编写默认项，减少手机端重复选择
- **权限范围**：显示为只读 / 工作区写入 / 完全访问；启用完全访问前再次确认
- **其他**：归档工作区的会话不再显示为额外工作区分组；更新应用图标、启动动画和 Android 构建工具

### 安装

1. 下载下方 `Anya-v0.1.9.apk` 并允许安装未知应用。已安装旧版的可在 **关于** 里检查更新。
2. 在 Windows 中打开 Anya → **连接手机**，等待二维码。
3. 手机扫码。尽量与电脑同一 Wi-Fi。

查看当前代码文件需要桌面端提供 `session.readCodePreview`；不支持时仍可查看读取时快照。完整设置文件和密钥不会同步到手机。

## What's new

- **Results inbox**: grouped by chat with chat and result totals, a clearer action row and group cards, and a fix for clear confirmation doing nothing. Clearing removes result records on the phone, while chats and downloaded files remain
- **Code reads**: expand a successful read to inspect its captured snapshot. With the desktop `session.readCodePreview` RPC, compare it against the current file; keep the snapshot if the file changed or cannot be read
- **New chat defaults**: use model and compose defaults from the paired desktop, cached per device
- **Permission scope**: Read-only / Workspace-write / Full-access, with confirmation before enabling Full-access
- **Other**: avoid extra groups for archived workspaces; refreshed app icon, launch animation, and Android build tools

### Install

1. Download `Anya-v0.1.9.apk` below (or **Check for updates** on About if you already have an older build).
2. Open Anya on Windows → **Connect phone**, wait for the QR.
3. Scan. Prefer the same Wi-Fi as the PC.

Current-file comparison requires desktop support for `session.readCodePreview`; captured snapshots remain available without it. Full settings and credentials are not synchronized to the phone.

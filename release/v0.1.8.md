# Anya Companion v0.1.8

After [v0.1.7](../CHANGELOG.md#017---2026-09-04): parity with desktop Anya 0.2.23 — Diff review, session/workspace management, Slash commands, environment context, chart export, and one unified liquid-glass stack.

Agent still runs on the PC. This app is a console: pair, chat, approve tools, and share files.

Requires a running desktop Anya with **Connect phone** / Remote Gateway enabled, and desktop Anya ≥ **0.2.23** for the new RPCs. Android 8.0+.

## 中文

相对 [v0.1.7](../CHANGELOG.zh-CN.md#017---2026-09-04)：对齐桌面 Anya 0.2.23，新增 Diff 审查、会话/工作区管理、Slash 命令、环境上下文与图表导出。

需要桌面端已打开 **连接手机**（Remote Gateway）；新 RPC 需要桌面 Anya ≥ **0.2.23**。最低 Android 8.0。

### 相对 v0.1.7

- **审查更改**：顶栏入口，支持本轮 / 未提交 / 整会话三种范围；Diff 查看器为统一视图（手机端不做分栏）
- 长按会话可 **重命名**；长按工作区可 **置顶 / 改名**
- 输入 `/` 打开 Slash 命令（`/model` `/thinking` `/history` `/work` `/context` `/settings` `/clear` `/exit`）
- `/context` 拉取桌面环境上下文；消息内渲染图片分析卡、选区卡与 SoftInject 折叠卡
- 图表卡片可 **导出 PNG** 分享
- 液态玻璃统一为一套：`backdrop` 1.0.2 → 1.0.6，底部导航选中胶囊改为随选项滑动的真实玻璃层；聊天顶栏与子页面（设置、归档）改用同一套折射，不再保留第二套模糊库

## What's new

- **Review changes**: top-bar entry with round / uncommitted / session scopes; the Diff viewer renders unified only
- Long-press a chat to **rename**; long-press a workspace to **pin / rename**
- Type `/` for Slash commands (`/model` `/thinking` `/history` `/work` `/context` `/settings` `/clear` `/exit`)
- `/context` fetches live desktop environment context; message bubbles render image-analysis cards, selection cards, and foldable SoftInject
- Chart cards can **export PNG** for sharing
- Liquid glass is one stack now: `backdrop` 1.0.2 → 1.0.6, the bottom nav's selected pill is a real glass layer that slides between items, and the chat top bar plus page chrome (settings, archived chats) refract through that same layer instead of a second blur library

### Install

1. Download `Anya-v0.1.8.apk` below (or **Check for updates** on About if you already have an older build).
2. Open Anya on Windows → **Connect phone**, wait for the QR.
3. Scan. Prefer the same Wi-Fi as the PC.

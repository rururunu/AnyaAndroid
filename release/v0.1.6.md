# Anya Companion v0.1.6

After [v0.1.5](../CHANGELOG.md#015---2026-09-03): a shared staged-message queue with the desktop, an in-app color theme, conversation cache hit rate, and a fix for threads that went blank after the agent stopped.

Agent still runs on the PC. This app is a console: pair, chat, approve tools, and share files.

Requires a running desktop Anya with **Connect phone** / Remote Gateway enabled. Staged messages need desktop **≥ 0.2.18**. Android 8.0+.

### 相对 v0.1.5

- **暂存队列**：Agent 运行中发消息会进入与桌面同步的队列；**引导** 为软注入，本轮结束后自动发出下一条
- **主题**：设置 → 通用，跟随系统 / 浅色 / 深色
- **缓存命中**：上下文占用面板显示本对话 DeepSeek prompt cache 命中率

- **空会话**：暂存 RPC 的空 `messages` 不再把聊天记录清掉
- **输入框**：附加内容后草稿仍可编辑、可滚动

### 安装

1. 下载下方 `Anya-v0.1.6.apk` 并允许安装未知应用。已安装旧版的可在 **关于** 里检查更新。
2. 在 Windows 中打开 Anya → **连接手机**，等待二维码。
3. 手机扫码。尽量与电脑同一 Wi-Fi。暂存队列请升级桌面端到 0.2.18+。

## What's new

- Busy send stages the message on the shared desktop queue; **Guide** soft-injects; the next staged line is sent when the turn ends
- Theme: follow system / light / dark under Settings → General
- Conversation cache hit rate on the context-usage sheet
- Jelly-bounce haptic when tapping the mascot
- Staged-queue RPC payloads no longer wipe chat history
- Composer stays editable and scrollable after attaching chips

### Install

1. Download `Anya-v0.1.6.apk` below (or **Check for updates** on About if you already have an older build).
2. Open Anya on Windows → **Connect phone**, wait for the QR.
3. Scan. Prefer the same Wi-Fi as the PC. Staged messages need desktop 0.2.18+.

Desktop: https://github.com/rururunu/Anya  
Docs: https://github.com/rururunu/AnyaAndroid

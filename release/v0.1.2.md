# Anya Companion v0.1.2

Patch after [v0.1.1](./v0.1.1.md): tapping **Get file** on a desktop share now hits the PC instead of the phone’s loopback, and Windows paths resolve.

Agent still runs on the PC. This app is a console: pair, chat, approve tools, and share files.

Requires a running desktop Anya with **Connect phone** / Remote Gateway enabled. Android 8.0+.

---

## 中文

相对 [v0.1.1](./v0.1.1.md)：桌面分享卡片上的「获取文件」会打到电脑，不再连手机自己的 `127.0.0.1:8787`；Windows 绝对路径也会先收成工作区相对路径。

需要桌面已打开 **连接手机**（Remote Gateway）。最低 Android 8.0。

### 相对 v0.1.1

- **下载地址**：桌面签发的 `http://127.0.0.1:8787/…` 改写到当前局域网或 Cloudflare 隧道
- **路径**：`file.download.begin` 优先工作区相对路径；失败则回退 `workspace.readFile` 分片
- **空格路径**：`share_to_companion` 的 Windows 路径不再在第一个空格处被截断

### 安装

1. 下载下方 `Anya-v0.1.2.apk` 并允许安装未知应用。已装旧版的可在 **关于** 里检测更新。
2. 在 Windows 上打开 Anya → **连接手机**，等待二维码。
3. 手机扫码。尽量与电脑同一 Wi-Fi。

桌面仓库：https://github.com/rururunu/Anya  
说明：https://github.com/rururunu/AnyaAndroid

## What's new

- Rewrite desktop-minted download URLs (`http://127.0.0.1:8787/…`) onto the live LAN or tunnel origin
- Prefer a workspace-relative path for `file.download.begin`; fall back to `workspace.readFile` slices
- Keep spaces in Windows `share_to_companion` paths

### Install

1. Download `Anya-v0.1.2.apk` below (or **Check for updates** on About if you already have an older build).
2. Open Anya on Windows → **Connect phone**, wait for the QR.
3. Scan. Prefer the same Wi-Fi as the PC.

Desktop: https://github.com/rururunu/Anya

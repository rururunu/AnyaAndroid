# Anya Companion v0.1.0

First public release of the Android remote for [desktop Anya](https://github.com/rururunu/Anya).

Agent still runs on the PC. This app is a console: pair, chat, approve tools, and share files.

Requires a running desktop Anya with **Connect phone** / Remote Gateway enabled. Android 8.0+.

---

## 中文

Anya Companion 的第一个公开版本：桌面 [Anya](https://github.com/rururunu/Anya) 的安卓远程控制台。Agent 仍在电脑上运行。

需要桌面已打开 **连接手机**（Remote Gateway）。最低 Android 8.0。

### 能力

- **配对**：扫描桌面二维码，或手动填写主机 / 令牌；深度链接 `anya://pair`
- **对话**：与电脑同一批会话；流式回复、取消；Ask / Agent / Plan
- **审批**：工具允许一次 / 本会话 / 拒绝，以及 `ask_user` 与计划批准
- **文件**：手机附件分片上传、桌面分享分片下载，单文件上限 500MB
- **连接**：同一 Wi-Fi 优先局域网 `ws://`；外出走 Cloudflare Quick Tunnel `wss://`
- **更新**：关于页检测 GitHub Releases（本文件 + `latest.json`）

### 安装

1. 下载下方 `Anya-v0.1.0.apk` 并允许安装未知应用。
2. 在 Windows 上打开 Anya → **连接手机**，等待二维码。
3. 手机扫码。尽量与电脑同一 Wi-Fi。

桌面仓库：https://github.com/rururunu/Anya  
说明：https://github.com/rururunu/AnyaAndroid

## Highlights

- Pair with the desktop QR (or paste host / token)
- Same sessions as the PC: stream, cancel, Ask / Agent / Plan
- Tool approvals, `ask_user`, and plan cards
- Chunked file transfer up to 500MB either direction
- LAN first, Cloudflare Tunnel fallback
- In-app updates from this GitHub Release

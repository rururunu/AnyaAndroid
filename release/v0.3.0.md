# Anya Companion v0.3.0

After [v0.1.9](./v0.1.9.md): paste a desktop pairing link, catch up on files and links missed while the phone was offline, and recover a quiet socket without waiting for the next send to fail.

Agent still runs on the PC. This app is a console for pairing, chatting, approvals, and shared files. Requires a running desktop Anya with **Connect phone** / Remote Gateway enabled. Android 8.0+.

## 中文

相对 [v0.1.9](./v0.1.9.md)：可以粘贴桌面配对链接，断线期间错过的文件和链接会在重连后补上，长时间没有数据的连接会自己断开并重拨。

### 本次更新

- **链接配对**：配对页新增「链接配对」，粘贴桌面分享的 `anya://pair` 或 `anya-companion://pair`。扫码和手填主机 / 令牌仍然可用
- **断线补收**：重连后用 `delivery.list` 按本机游标补拉文件和链接。已经保存的文件保留本地副本，不会重复下载。更旧的桌面若不支持该 RPC，实时分享卡片照常工作
- **会话列表**：随问和工作区不再列出插件会话（`plugin:`）和子代理会话（id 含 `-sub-`）
- **连接**：桌面 ping 在套接字上直接回复；手机每 20 秒发送保活；连续 45 秒没有入站数据则回收连接。回到应用时检查连接并补拉交付
- **外观**：应用图标、启动页和对话状态改为 Anya 眼睛

### 安装

1. 下载下方 `Anya-v0.3.0.apk` 并允许安装未知应用。已安装旧版的可在 **关于** 里检查更新。
2. 在 Windows 中打开 Anya → **连接手机**，等待二维码或复制配对链接。
3. 手机扫码或粘贴链接。尽量与电脑同一 Wi-Fi。

`delivery.list` 需要桌面实现该接口。完整设置文件和密钥不会同步到手机。

## What's new

- **Link pairing**: **Pair with a link** on the pairing screen accepts a pasted `anya://pair` or `anya-companion://pair` URL. QR and manual host / token remain
- **Offline catch-up**: after reconnect, `delivery.list` pages file and URL offers from a cursor stored on the phone. A file already saved keeps its local copy. Desktops without that RPC still deliver live offer cards
- **Session lists**: Ask and Workspace hide plugin sessions (`plugin:`) and sub-agent sessions (ids containing `-sub-`)
- **Connection**: desktop pings are answered on the socket; the phone sends a keep-alive every 20 seconds; 45 seconds without inbound traffic recycles the link. Returning to the app checks the socket and syncs deliveries
- **Look**: app icon, splash, and the chat status mascot use the Anya eyes

### Install

1. Download `Anya-v0.3.0.apk` below (or **Check for updates** on About if you already have an older build).
2. Open Anya on Windows → **Connect phone**, wait for the QR or copy the pairing link.
3. Scan or paste the link. Prefer the same Wi-Fi as the PC.

`delivery.list` requires a desktop that implements it. Full settings and credentials are not synchronized to the phone.

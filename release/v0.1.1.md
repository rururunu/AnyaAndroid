# Anya Companion v0.1.1

Follow-up to [v0.1.0](./v0.1.0.md): multiple desktops, a named host, and an inbox that still works after you leave the chat.

Agent still runs on the PC. This app is a console: pair, chat, approve tools, and share files.

Requires a running desktop Anya with **Connect phone** / Remote Gateway enabled. Android 8.0+.

---

## 中文

相对 [v0.1.0](./v0.1.0.md)：可以同时连多台电脑、给主机起名，离开对话后仍能在收件里处理审批和文件。

需要桌面已打开 **连接手机**（Remote Gateway）。最低 Android 8.0。

### 相对 v0.1.0

- **多主机**：保存多台桌面；设置里的主机列表切换，或长按左上角 logo 切换
- **显示名**：配对时最多 16 字；顶栏「Anya」会换成该名称
- **重新配对**：隧道域名 / 令牌变了，对该主机重新扫码，名称与 deviceId 保留
- **收件 · 待确认**：桌面 Agent 卡住时，同一条审批 / 提问会出现在这里
- **收件 · 结果**：桌面分享的文件与链接；可后台分片下载，通知栏看进度
- **设置**：主机列表、重连 / 重新配对 / 解除配对、改名

### 安装

1. 下载下方 `Anya-v0.1.1.apk` 并允许安装未知应用。已装 v0.1.0 的可在 **关于** 里检测更新。
2. 在 Windows 上打开 Anya → **连接手机**，等待二维码。
3. 手机扫码，给这台主机起一个短名称。尽量与电脑同一 Wi-Fi。

桌面仓库：https://github.com/rururunu/Anya

## What's new

- Save several desktops; switch from Settings or by long-pressing the logo
- Host display name (max 16 characters) in the top bar
- Re-pair a saved host when the tunnel URL or token rotates (name is kept)
- Inbox **Pending**: the same tool / ask_user gates the desktop is blocked on
- Inbox **Results**: files and links from `share_to_companion`; background chunked download with a notification
- Settings host list: reconnect, re-pair, rename, unpair

### Install

1. Download `Anya-v0.1.1.apk` below (or **Check for updates** on About if you already have v0.1.0).
2. Open Anya on Windows → **Connect phone**, wait for the QR.
3. Scan, give the host a short name. Prefer the same Wi-Fi as the PC.

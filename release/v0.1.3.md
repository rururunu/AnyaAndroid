# Anya Companion v0.1.3

Feature release after [v0.1.2](./v0.1.2.md): the chat model picker now mirrors desktop provider metadata, exposes compatible thinking controls, and shows a live context estimate.

Agent still runs on the PC. This app is a console: pair, chat, approve tools, and share files.

Requires a running desktop Anya with **Connect phone** / Remote Gateway enabled. Android 8.0+.

---

## 中文

相对 [v0.1.2](./v0.1.2.md)，聊天模型选择器会使用桌面端的提供商元数据与图标，根据模型显示兼容的思考控件，并实时显示上下文估算值。

需要桌面端已打开 **连接手机**（Remote Gateway），并支持 `context.usage` 和 compose `reasoningEffort`。最低 Android 8.0。

### 相对 v0.1.2

- **模型选择**：按提供商分组，使用桌面端名称、图标与常见提供商标识
- **思考控件**：优先显示桌面端下发的思考变体，其他模型按兼容性提供推理强度选择
- **上下文占用**：随当前模型和草稿实时刷新估算值
- **状态同步**：选定的推理强度会同步到桌面端；旧版桌面响应缺少该字段时保留本地选择

### 安装

1. 下载下方 `Anya-v0.1.3.apk` 并允许安装未知应用。已安装旧版的可在 **关于** 里检查更新。
2. 在 Windows 中打开 Anya -> **连接手机**，等待二维码。
3. 手机扫码。尽量与电脑同一 Wi-Fi。

桌面仓库：https://github.com/rururunu/Anya  
说明：https://github.com/rururunu/AnyaAndroid

## What's new

- Provider-grouped model picker with desktop-provided names and logos
- Per-model thinking variants or a compatible reasoning-effort selector
- Live context-usage estimate for the selected model and current draft
- Reasoning effort synchronized with desktop compose state, with compatibility for older responses

### Install

1. Download `Anya-v0.1.3.apk` below (or **Check for updates** on About if you already have an older build).
2. Open Anya on Windows -> **Connect phone**, wait for the QR.
3. Scan. Prefer the same Wi-Fi as the PC.

Desktop: https://github.com/rururunu/Anya  
Docs: https://github.com/rururunu/AnyaAndroid
